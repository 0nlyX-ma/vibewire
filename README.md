# VIBEWIRE Desktop App

VIBEWIRE is a desktop application that was initially developed using Python. However, to enhance its performance and improve the user interface, we have transitioned the application to a Next.js/Electron framework.

## Key Changes
- **Performance**: The migration to Next.js/Electron allows for a more responsive and faster user experience.
- **UI Improvements**: This transition has also enabled us to implement a more modern and visually appealing interface for our users.
