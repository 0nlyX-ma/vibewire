# VIBEWIRE 🎬

A modern desktop application to track your favorite YouTube channels and stay updated with the latest uploads.

## 📖 Story

**VIBEWIRE** started as a Python project, but I realized I needed better performance, a sleeker UI, and a more polished desktop experience. So I **rewrote it from scratch using Next.js + Electron**, and the result is this lightning-fast, beautiful desktop app!

### Why the switch?
- 🐌 **Python** → Slower, limited UI options
- ⚡ **Next.js + Electron** → Fast, modern, beautiful interface
- 🎨 Better design and user experience
- 🚀 Better performance and responsiveness

---

## ✨ Features

✅ Track YouTube channels  
✅ Real-time notifications  
✅ Beautiful, modern UI  
✅ Fast and responsive  
✅ Desktop app (Windows, Mac, Linux support)

## 🚀 Getting Started

### Download
[**Download VIBEWIRE v1.0.0**](https://github.com/0nlyX-ma/vibewire/releases/tag/v1.0.0)

1. Download the `.exe` installer
2. Run it
3. Install and launch VIBEWIRE
4. Start tracking your favorite channels!

### For Developers

```bash
# Clone the repo
git clone https://github.com/0nlyX-ma/vibewire.git
cd vibewire

# Install dependencies
npm install

# Run in dev mode
npm run dev

# Build desktop app
npm run electron:build
